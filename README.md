# AI CS 指挥台

面向客户成功（CS）/运营团队的 AI 工作流工具：把客户分层、场景筛选、价值传递、交付设计、价值验证、客情关怀、汇报输出等关键动作，浓缩进一个浏览器应用，用 AI 辅助团队每天的关键决策与执行。

## 功能模块

| 模块 | 作用 |
|------|------|
| 客户分层 | 粘贴客户数据，AI 自动分层 S/A/B/C，输出优先客户 |
| 场景筛选 | 按业务场景筛选客户，聚焦高价值机会 |
| 价值传递 | 选客户类型，AI 生成标准化价值方案与话术 |
| 交付设计 | 粘贴客户问题，AI 生成跨岗协同任务卡推送到看板 |
| 价值验证 | 填今日数据，AI 算账找卡点，明确明天动作 |
| 客情关怀 | 选重点客户，AI 批量生成个性化关怀消息 |
| 汇报输出 | 填核心数据 + 卡点，AI 生成日报初稿 |
| 知识库 | 沉淀团队话术/方案/FAQ，供 AI 调用 |
| 任务卡与团队协同 | 任务卡流转 + 团队工作区协作 |
| 工作区跟踪 | 团队执行进度可视化 |

## 技术栈

- **前端**：React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui
- **AI 能力**：多模型接入（OpenAI 兼容协议，支持 DeepSeek / 通义 / 智谱等），API Key 用户自填、仅存本地
- **数据存储**：IndexedDB（本地持久化，无需后端）
- **扩展能力**：飞书开放平台对接（Webhook 鉴权、多维表读写、token 刷新）

## 快速开始

```bash
npm install
npm run dev      # 开发环境
npm run build    # 生产构建（输出到 dist/）
```
